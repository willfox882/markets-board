# Architecture: file map (one line per file)

## Root
- `CLAUDE.md`: agent entry point (commands, conventions, design rules).
- `README.md`: human overview.
- `settings.gradle.kts`, `build.gradle.kts`, `gradle.properties`, `gradle/libs.versions.toml`: Gradle setup and version catalog.
- `local.properties`: sdk.dir (gitignored). `.gitignore`: build outputs, local.properties, *.apk.
- `.github/workflows/build.yml`: CI (tests, assembleDebug, lintDebug, sandboxJar, artifacts).
- `docs/PLAYBOOK.md`: orchestrator brief and milestone plan (do not edit). `docs/PROGRESS.md`: state and decisions. `docs/SANDBOX.md`: desktop simulator. `docs/licenses/OFL-Geist.txt`: font licence.

## shared/ (compiled by both :app and :sandbox)
- `shared/res/font/geist_{light,regular,medium,semibold}.ttf`: Geist weights (Android `R.font`, desktop classpath `font/`).
- `shared/src/main/kotlin/com/marketsboard/ui/Theme.kt`: `Dash` palette, `Tabular`, `DashFonts` hook, `MarketsBoardTheme`.
- `.../ui/Components.kt`: Label, ScreenTitle, Hairline, Dot, DashCard, Numeral, StatGrid, PillButton, TextAction, SectionHeader, SwitchRow, ValueRow, DashDialog, Skeleton, TextToggle (light text tabs on a hairline), `changeColor` and `liveDotColor` (the only two users of green/red).
- `.../ui/Format.kt`: pure formatting (formatPrice, formatSigned, formatPercent, changeSign, formatTimeAgo), typographic minus; one BigDecimal rounding step shared by text, sign and colour.
- `.../ui/DesignScale.kt`: `DesignScale` (440 dp design width), `LocalBackHook` and `LocalOpenUrl` (platform hook that opens an http(s) link; default no-op).
- `.../ui/MarketsBoardRoot.kt`: `MbTab` enum and the tabbed shell with hairline bottom bar; takes `MarketsUiState` + `NewsUiState` + `MarketsActions` + `NewsActions` + `UiMode` from the caller; the tab bar steps aside for the Markets detail/add sheet and the News article.
- `.../ui/charts/Charts.kt`: `LineChart` (optional dashed baseline), `BarChart`, `Sparkline`, `downsample`.
- `.../ui/markets/MarketsUi.kt`: UI models (`QuoteRowUi` + `RowStatus`, `HeaderUi`, `DetailUi`, `AddUi`, `SearchRowUi`, `MarketsUiState`) and the `MarketsActions` interface (every user action; `None` default).
- `.../ui/markets/UiMapper.kt`: pure mapping from `QuoteState` to rows, header ("Live"/"Delayed"/"Offline"/"Markets closed"), clock-skew flag and the detail model.
- `.../ui/markets/MarketsPresenter.kt`: `StateFlow<MarketsUiState>` from watchlist + quotes + navigation; implements all actions (edit mode, move, rename, remove, add/replace flow with 400 ms debounced search, detail range loading, back order).
- `.../ui/markets/Suggestions.kt`: the owner's quick-add list (never on by default).
- `.../ui/markets/MarketsScreen.kt`: Markets tab: header (title, Refresh, live dot + "Updated 12:41 PM ET"), clock banner, watchlist, edit mode, empty state, overlays (detail, add sheet, confirm and rename dialogs).
- `.../ui/markets/QuoteRow.kt`: the row (name up to 2 lines + price, symbol/exchange + change, full-width sparkline strip, skeleton, stale/error status band with Retry, dimmed numbers), `GlanceRow`, `EditRow` with `EditAction` buttons, `ArrowButton` (spoken labels), `BackChevron`, `priceFontSizeSp`.
- `.../ui/markets/DetailScreen.kt`: instrument detail (back, price, change, 1D/5D/1M/3M/1Y pills, line chart with previous-close baseline, `StatGrid`, Replace, Remove).
- `.../ui/markets/AddSheet.kt`: full-screen add / replace sheet (search field, outcome message, "Add anyway", results with "Added" badge, suggestions).
- `.../core/NewsTexts.kt`: `NewsText`: "now / 5m ago / 3h ago / 2d ago", "Updated 12 min ago", plain-language feed errors.
- `.../core/Briefing.kt`: `Briefings.build`: the spoken market briefing (greeting, caveats, instruments with the currency said only when not CAD, up to 3 unread headlines from the last 24 h, 42 s / 110 word budget from a speaking-time estimate) as `Utterance`s with pauses plus the ids it used; structured ages, no UI-string parsing; pure text, no audio.
- `.../core/Texts.kt`: `ErrorText` (plain-language reasons, rate-limit countdown), `AddText` (outcome messages), `ExchangeLabels` (Toronto to TSX, NasdaqGS to NASDAQ), `TypeLabels`, `ExchangeTime` (exchange-zone time text, ET/CT/MT/PT labels).
- `.../core/MarketPhase.kt`: market open (REGULAR/PRE/POST) vs closed from `marketState` or the session window, for the header status.
- `.../core/PollPolicy.kt`: poll interval per market phase (60 s live, 5 min PRE/POST, 30 min or next session start when closed); also the basis of the repository's market-aware stale limit.
- `.../refresh/RefreshController.kt`: the refresh policy (per-phase intervals from `PollPolicy`, immediate on start/resume/symbol-SET change, resume-after-sleep rules, network-available pass, 15 s age recompute, pause when inactive, cooldown aware, never under 60 s per symbol, manual debounce), `Refresher`, `RefreshConfig`.
- `.../refresh/ActiveGate.kt`: foreground gate (`isActive`, `resume`, `pause`, `launchWhileActive`); gates the quote controller and the news poller.
- `.../refresh/NewsPoller.kt`: news polling policy (hydrate cache, pass on resume, every 10 min while active, network-back retries failed feeds, config change retags and fetches, ages tick, debounced forced manual refresh) + `NewsRefresher`, `NewsPollConfig`.
- `.../refresh/NetworkSignal.kt`: interface for "network became available" (Android implements it).
- `.../ui/UiMode.kt`: `Normal` / `Glance`; driven by `DrivingGate.mode`.
- `.../ui/GlanceRules.kt`: the Glance contract: `MarketsAct`, `NewsAct`, `SettingsAct` enums (one entry per presenter action, each Allowed or Blocked in Glance); presenters route every action through `guarded(Act.X)`.
- `.../data/MarketsData.kt`: watchlist + quotes + provider bundle; remove/replace/reset that also `forget`, `validateAndReplace`, `replaceUnverified`.
- `.../data/repo/QuotesSource.kt`: interface of what UI and controller need from `QuoteRepository` (fakeable).
- `.../data/store/Watchlist.kt`: interface implemented by `WatchlistStore` (fakeable).
- `.../ui/news/NewsUi.kt`: News UI models (`NewsUiState`, `NewsPhase` Loading/Ready/Empty/Error, `HeadlineRowUi`, `HeadlineDetailUi`, `NewsFilter`) and the `NewsActions` interface.
- `.../ui/news/NewsMapper.kt`: pure `NewsState` to `NewsUiState` (filter, glance top 3, banner and stale rules, "3h ago", detail with the published time in the device zone).
- `.../ui/news/NewsPresenter.kt`: `StateFlow<NewsUiState>` from the repository (`NewsSource`) + filter/open-article navigation + `UiMode` + a 30 s tick for the ages; glance closes an open article.
- `.../ui/news/NewsScreen.kt`: News tab: header + status line, amber banner with Retry, All / My symbols switch, hairline headline rows (source, age, tags, 3-line title, 2-line summary), skeletons, empty and error states, glance rows, and the article detail with the Open article button (`LocalOpenUrl`).
- `.../ui/settings/SettingsScreen.kt`: the Settings tab (Driving: passenger switch, lock explanation, live status and reason, Grant location permission; Briefing: voice, speech rate stepper, headlines, media key, engine status; About: version, build, data sources, "Markets data may be delayed").
- `.../ui/settings/SettingsUi.kt`: `SettingsUiState`, `SettingsActions`, `AboutInfo`, `LocationAccess` (platform permission hook).
- `.../ui/settings/SettingsPresenter.kt`: Settings state over `AppSettingsStore` + `DrivingGate` status; every action blocked in Glance.
- `.../ui/briefing/BriefingUi.kt`: `BriefingBand` (Normal caption under the top strip), `GlanceLower` (big Brief me / caption + Stop in Glance), `BigPill`.
- `.../core/DrivingGate.kt`: the safety gate (speed samples to `UiMode` + `DrivingReason`), `DrivingStatus`, `DrivingConfig`, `DrivingTexts`, `DrivingGate.bind`.
- `.../core/SpeedSamples.kt`: pure conversion of one GPS fix (speed, age, accuracy) into a km/h sample or null.
- `.../speech/SpeechMachine.kt`: the pure generation, focus and engine-lifecycle logic of the speaker (`SpeechPlatform` is what Android provides); `AndroidSpeaker` is a thin adapter.
- `.../ui/DrivingUi.kt`: `DrivingActions` (the 3 s "I am parked" hold).
- `.../speech/Speaker.kt`: `Speaker` interface, `SpeakerState` (Idle, Preparing, Speaking, Finished, Error), `SpeakerFault`, `SpeakerAvailability`.
- `.../briefing/BriefingController.kt`: "Brief me" flow (refresh with 8 s timeout, `Briefings.build`, speak, caption, stop, double tap, background, focus loss, text fallback, alreadySpoken persistence), `BriefingUiState`, `BriefingActions`, `BriefingSource`, `BriefingSnapshot`.
- `.../briefing/LiveBriefingSource.kt`: `BriefingSource` over `MarketsData` and `NewsSource`.
- `.../briefing/BriefingTrigger.kt`: `BriefingTrigger` + `TriggerSource` (button, media key, future steering wheel).
- `.../data/settings/JsonFileStore.kt`: shared atomic versioned JSON file pattern (fsync, rename, backup, quarantine, newer version read-only).
- `.../data/settings/AppSettingsStore.kt`: `AppSettings` and `settings.json` v1 (passenger, voice, rate 0.8 to 1.2, headlines, media key).
- `.../data/settings/BriefingHistoryStore.kt`: `BriefingHistory` and `briefing-history.json` (ids of headlines already read, newest 300).
- `.../data/Clock.kt`: injectable clock: wall `nowMs` (persisted times, skew detection) and monotonic `monoMs` (in-process ages, throttling, cooldowns); never used for market timestamps.
- `.../data/model/Models.kt`: `Instrument`, `WatchItem`, `ChartRange` (+ Yahoo range/interval), `SeriesPoint`, `Quote` (provider-time `asOfEpochMs`, `source`, session window, timezone, `priceHint`/`decimals`), `Currencies` (GBp to GBX etc), `ErrorKind` (incl. `ClockOrTls`), `FetchResult` (Ok/Err), `QuoteValidator` (price/series sanity rules).
- `.../data/net/HttpFetcher.kt`: `HttpFetcher` interface, `HttpResponse` (typed `failure`, `toError()`, parsed Retry-After), `hostOf` (log-safe host).
- `.../data/net/JvmHttpFetcher.kt`: HttpURLConnection implementation: timeouts, gzip, 20 s whole-fetch deadline, disconnect on cancel, manual redirects (max 3, no scheme downgrade), 2 MB cap, error bodies, `offline` and cert-date detection, never throws.
- `.../data/net/FetchLog.kt`: `FetchEvent`, `FetchLog` (100-event ring buffer as StateFlow) and `LoggingHttpFetcher` decorator (host only, latency, outcome).
- `.../data/provider/MarketDataProvider.kt`: provider interface (`quote`, `search`, `supports(symbol)` and `supports(symbol, range)`).
- `.../data/provider/JsonSupport.kt`: defensive accessors over the kotlinx.serialization `JsonElement` tree (wrong type or null becomes null).
- `.../data/provider/YahooChartProvider.kt`: Yahoo chart + search provider (query1, query2 fallback host) and the pure `YahooParser`.
- `.../data/provider/StooqProvider.kt`: best-effort Stooq CSV fallback, `YahooToStooq` symbol mapping, `StooqParser`.
- `.../data/store/FileJsonCache.kt`: directory cache: atomic writes, per-entry TTL, total size cap with oldest-first eviction, corrupt tolerant.
- `.../data/store/QuoteCodec.kt`: JSON encode/decode (re-validating) of a `Quote` for the cache.
- `.../data/store/Symbols.kt`: symbol normalisation (`A-Z0-9.^=-`, 1..15).
- `.../data/store/WatchlistStore.kt`: the owner's watchlist: `watchlist.json` v1 (+ `watchlist.bak`), defaults XEQT.TO + MSFT, add/remove/move/rename/replace/reset, `validateAndAdd`, `addUnverified`, fsync'ed atomic writes, backup recovery, corrupt/newer-version handling, `flushIfDirty`, `EditResult` and `AddOutcome`.
- `.../data/repo/QuoteState.kt`: `QuoteState`, `QuoteStatus` (Fresh/Stale/Loading/Error) and `RepoConfig` (tunables).
- `.../data/repo/QuoteRepository.kt`: stale-while-revalidate quote repository: provider chain with fallback merge, cooldown/backoff, 4-way concurrency cap, network short-circuit, in-flight dedup, monotonic ages, clock skew, `forget`, cancellation safe.

- `.../data/news/NewsModels.kt`: `FeedConfig`/`FeedKind`, `Headline`, `FeedState`/`FeedStatus`, `NewsOverall` (Loading/Fresh/Stale/Error), `NewsState`.
- `.../data/news/PlainText.kt`: HTML to plain text (tags, scripts, comments, entities, whitespace, word-boundary clamp, em/en dashes to hyphens) and the entity table.
- `.../data/news/FeedDates.kt`: RFC 822/1123 variants, ISO 8601 variants and epoch numbers; null when unusable.
- `.../data/news/XmlText.kt`: bytes to text (BOM, declared encoding, HTTP charset) and the sloppy-XML repair (illegal characters, HTML entities, stray ampersands).
- `.../data/news/FeedParser.kt`: hardened `XmlPullParser` (platform KXmlParser on Android, kxml2 on the JVM) parser for RSS 2.0, RSS 1.0 (RDF) and Atom; a linear whole-input DOCTYPE scan refuses any DOCTYPE, size/depth/item caps, http(s) links only (`safeFeedUrl`: https only), partial salvage (a cut-off document counts as an error), typed Parse errors, dates more than 5 min ahead replaced.
- `.../data/news/Dedupe.kt`: canonical URL, normalised title, token Dice similarity (looser when summaries are identical); title and summary rules join only items of DIFFERENT feeds within 12 h and never when the titles move opposite ways (rise/fall words); merge keeps the earliest report and the union of tags.
- `.../data/news/Relevance.kt`: `SymbolMatcher` (ticker upper case whole word, company names, distinctive first word) and `Relevance.labelOf`.
- `.../data/news/FeedStore.kt`: `FeedStore` (`feeds.json` v1, fsync'd atomic writes, `.bak`, corrupt quarantine, newer-version read-only; add/remove/enable/rename/move/reset), `FeedSource`, `DefaultFeeds`, `FeedPlan` (effective feeds, auto per-symbol Yahoo feeds, cap 6).
- `.../data/news/NewsCodec.kt`: JSON of one feed's cached items plus ETag/Last-Modified (`FeedSnapshot`), re-validated on read.
- `.../data/news/NewsRepository.kt`: fetch (max 3 parallel), conditional GET, per-feed health and exponential backoff (network/timeout errors capped at 10 min), offline short-circuit, requests during a running pass queued as one follow-up, an attempt counts only when it finishes, merge/dedupe/retag/sort/cap/7-day cut, SWR cache hydrate (a cache from a clock ahead of the device is Stale with an unknown age), median server `Date` offset (with `Age`), dominant error kind, `StateFlow<NewsState>`.
- `.../data/news/NewsSource.kt`: the small interface the presenter needs from the repository.

## app/ (Android)
- `app/build.gradle.kts`: Android module, shared srcDir + font res.
- `app/src/main/AndroidManifest.xml`: INTERNET, ACCESS_NETWORK_STATE, ACCESS_FINE/COARSE_LOCATION (foreground only), gps `uses-feature` not required, `<queries>` for the TTS service, portrait activity.
- `app/src/main/java/com/marketsboard/MainActivity.kt`: immersive, keep-screen-on, sets fonts, provides `LocalBackHook`, shows the root with the presenters' states, provides `LocalOpenUrl` (ACTION_VIEW in try/catch, http(s) only), sets `active` from onResume/onPause, runs the location permission request, starts and stops `LocationSpeedSource`, handles the media play/pause and headset hook keys.
- `app/src/main/java/com/marketsboard/AppGraph.kt`: hand-built dependency graph (fetcher, log, providers, cache in `filesDir/cache`, `WatchlistStore` in `filesDir/watchlist.json`, `QuoteRepository`, `MarketsData`, plus `FeedStore` in `filesDir/feeds.json` and `NewsRepository` on the same cache); takes a `File`, so it is JVM-testable.
- `app/src/main/java/com/marketsboard/AppRuntime.kt`: process-scoped `RefreshController` + presenters, `DrivingGate` (+ 1 s tick), `SettingsPresenter`, `BriefingController` on top of the graph; its `ActiveGate` is flipped by the Activity.
- `app/src/main/java/com/marketsboard/LocationSpeedSource.kt`: GPS provider at 1 Hz between onResume and onPause (no service), fixes to samples through `SpeedSamples`, nothing stored or logged.
- `app/src/main/java/com/marketsboard/AndroidLocationAccess.kt`: location permission state + request hook for the Activity.
- `app/src/main/java/com/marketsboard/AndroidSpeaker.kt`: `TextToSpeech` en-CA then en-US, assistant/speech audio attributes, may-duck audio focus, generation-tagged callbacks, failure states, shutdown.
- `app/src/main/java/com/marketsboard/AndroidClock.kt`: production `Clock` (monotonic = `elapsedRealtime`, so ages include deep sleep).
- `app/src/main/java/com/marketsboard/ConnectivityNetworkSignal.kt`: `NetworkSignal` from a ConnectivityManager default-network callback: fires on available and again when the network becomes VALIDATED (hotspot with working internet); shared by Markets and News.
- `app/src/main/java/com/marketsboard/MarketsBoardApplication.kt`: Application; builds `AppGraph` and `AppRuntime` (crash-proof, null on failure).
- `app/src/main/res/`: `values/themes.xml` (window bg #0A0A0B), `values/colors.xml`, `drawable/ic_launcher_fg.xml` (line chart glyph), `mipmap-anydpi-v26/ic_launcher.xml` (adaptive + monochrome).

- `app/src/test/kotlin/com/marketsboard/AppGraphTest.kt`: real wiring against fixtures (default watchlist quotes in CAD/USD, Stooq fallback, restart persistence, log hosts).
- `app/src/test/kotlin/com/marketsboard/UiTestSupport.kt`: `VirtualClock` and `SplitClock` (test scheduler time; the latter can 'sleep' wall time only), `FakeQuotesSource` (records calls), `FakeNetwork`, `FakeProvider` (scripted quote/search, late search answers).
- `app/src/test/kotlin/com/marketsboard/ui/UiMapperTest.kt`, `ui/MarketsPresenterTest.kt`, `refresh/RefreshControllerTest.kt`, `core/CoreTextsTest.kt`: M2 tests (row/header/detail mapping, editor and add/replace flow, search debounce, refresh policy with a fake clock, wording and exchange-time formatting).
